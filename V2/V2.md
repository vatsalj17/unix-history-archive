# V2 Source Code Archive

## Historical Overview
- **Release / Snapshot Date:** June 12, 1972
- **Authors & Key Contributors:** Ken Thompson, Dennis Ritchie, with contributions from Robert Morris and Doug McIlroy at Bell Telephone Laboratories.
- **Target Machine Architecture:** DEC PDP-11/20 (16-bit word minicomputer, 24 KB of physical core memory).
- **Historical Milestones:**
  - **The Birth and Dawn of C:** Second Edition marks the historic moment Dennis Ritchie evolved Ken Thompson’s typeless B language into **C**. Ritchie added types (`int`, `char`, pointer types, arrays, structures) and developed the very first C compiler to take advantage of the PDP-11’s byte-addressable architecture.
  - **Transitioning from Assembly to C:** While the core V2 kernel was still in assembly, userland commands and utilities began to be rewritten or newly written in C (such as `fc.c` and compiler tools).
  - **Archive Scope & Survival:** A full image of the V2 kernel did not survive in historical archives. The preserved V2 tree contains Dennis Ritchie's original C compiler (`c/`), 68 command-line utilities in PDP-11 assembly and C (`cmd/`), and the essential C runtime and system call library (`lib/`).
  - **Source Provenance:** The C compiler sources originated from `last1120c.tar.gz`, donated by Dennis Ritchie to the Unix Heritage Society (TUHS).

## Directory Tree & Navigation Map

```
V2/
├── c/                [Dennis Ritchie's original 1972 C compiler]
│   ├── ncc.c         [C compiler top-level driver]
│   ├── cvopt.c       [Code generation table optimizer/converter]
│   ├── nc0/          [Pass 0: Parser & lexical analysis (c00.c - c03.c, c0t.s)]
│   ├── nc1/          [Pass 1: PDP-11 code generator (c10.c, c11.c, c1t.s)]
│   ├── rt/           [C runtime library archive (libc.sa)]
│   └── *.s           [PDP-11 code generation translation tables (cctab, regtab...)]
├── cmd/              [68 userland commands, utilities, and assembler passes]
└── lib/              [C runtime startoff (crt0.s) and system call stubs]
```

### Subdirectory Breakdown
- `c/`: The historic root of Dennis Ritchie's C compiler. It implements the two-pass compiler architecture (`nc0` front-end and `nc1` code generator) with instruction tables.
- `cmd/`: Contains early Unix commands including the multi-pass PDP-11 assembler (`as11.s`–`as19.s`, `as21.s`–`as28.s`), text utilities (`ed1.s`–`ed9.s`, `cat.s`, `cp.s`, `ls.s`), desk calculator (`dc1.s`, `dc2.s`), and early C tools (`fc.c`).
- `lib/`: The PDP-11 assembly stubs providing standard system call wrappers and runtime glue for C binaries.

## Key Source Code Files

| Component / Subsystem | File Link | Description |
| :--- | :--- | :--- |
| **C Compiler Driver** | `c/ncc.c` | The top-level C compiler executable driver that manages pre-processing, compiler pass execution (`nc0`, `nc1`), and invoking the assembler and linker. |
| **C Parser (Pass 0)** | `c/nc0/c00.c` | Pass 0 lexical analyzer and expression parser: processes tokens, declarations, and parses syntax into tree structures. |
| **C Code Generator (Pass 1)** | `c/nc1/c10.c` | Pass 1 code generation for PDP-11: walks the parse tree and translates intermediate representation into PDP-11 machine instructions. |
| **Code Generation Tables** | `c/regtab.s`, `c/efftab.s` | Assembly translation tables mapping C operators (`+`, `-`, `*`, `&`, `|`, `++`) into optimal PDP-11 addressing modes and register instructions. |
| **C Runtime Startoff** | `lib/crt0.s` | The foundational startup routine linked into every C program: sets up the stack pointer, extracts `argc` and `argv`, calls `main()`, and traps into `sys exit`. |
| **System Call Stubs** | `lib/fork.s`, `lib/read.s`, `lib/write.s`, `lib/stat.s` | The bridge between C functions and the PDP-11 kernel `sys` trap interface. |
| **Native Assembler Passes** | `cmd/as11.s` – `cmd/as19.s` | Pass 1 and Pass 2 of the native PDP-11 assembler (`as`), implementing symbol table lookup, forward reference resolution, and binary object emission. |
| **Early C Command** | `cmd/fc.c` | One of the earliest user commands written in C: a Fortran compilation driver invoking passes and managing temporary files. |
| **Interactive Text Editor** | `cmd/ed1.s` – `cmd/ed9.s` | Complete assembly implementation of the standard text editor `ed`, partitioned into 9 modular assembly files. |
| **Desk Calculator** | `cmd/dc1.s`, `cmd/dc2.s` | Robert Morris's reverse-Polish arbitrary precision calculator `dc` written in PDP-11 assembly. |

## Recommended Exploration Path

To study the origins of the C language and early Unix userland:

1. **Investigate the Genesis of C Runtime:**
   Read `lib/crt0.s` and syscall wrappers like `lib/write.s` to see how early C compiled code interacted with hardware and kernel traps.
2. **Explore Dennis Ritchie's First C Compiler:**
   Start by examining `c/ncc.c` to understand compiler driver invocation, then explore the Pass 0 parser in `c/nc0/c00.c`.
3. **Analyze Code Generation & PDP-11 Architecture:**
   Inspect `c/nc1/c10.c` alongside the operator code tables in `c/regtab.s` to observe how C language expressions were mapped directly onto PDP-11 hardware registers.
4. **Inspect Early C Application Code:**
   Open `cmd/fc.c` to see the dialect of C written by Dennis Ritchie and Ken Thompson in mid-1972 before standard library conventions existed.
5. **Study the Native Assembler:**
   Trace `cmd/as11.s` through `cmd/as19.s` to see how the system bootstrap assembler was implemented.
