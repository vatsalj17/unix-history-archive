# V3 Source Code Archive

## Historical Overview
- **Release / Snapshot Date:** February 1973
- **Authors & Key Contributors:** Ken Thompson, Dennis Ritchie, with contributions from Douglas McIlroy, Robert Morris, and S. C. Johnson at Bell Telephone Laboratories.
- **Target Machine Architecture:** DEC PDP-11 (PDP-11/20 and the newly introduced PDP-11/45 with Memory Management Unit).
- **Historical Milestones:**
  - **The Invention of the Pipe (`pipe` system call):** Third Edition is the landmark edition where Douglas McIlroy's vision of pipelined computation ("programs connected like garden hoses") became reality. Ken Thompson implemented the `pipe` system call (system call #42) in a single night in early 1973, adding syntax into the shell so commands could be chained: `cmd1 | cmd2 | cmd3`.
  - **The Twilight of Assembly Unix:** V3 was the final release of Unix whose operating system kernel was written entirely in assembly language. Throughout 1973, Dennis Ritchie and Ken Thompson utilized this running V3 system to rewrite the kernel completely in C, which would debut in V4.
  - **Survival & Archive Status:** While the assembly kernel itself was not archived, the surviving Third Edition snapshot preserves Dennis Ritchie's early C compiler passes (`c/`) and the complete, authentic machine-readable manual pages (`man/`), providing extraordinary historical documentation of this transformative era.
  - **Source Provenance:** Compiled from Dennis Ritchie's compiler archives and the TUHS historical manual restoration collections.

## Key Source Code Files & Historical Manuals

| Component / Subsystem | File Link | Description |
| :--- | :--- | :--- |
| **C Lexer & Parser (Pass 0)** | `c/c00.c` | Dennis Ritchie's Pass 0 C compiler frontend: manages lexical scanning, preprocessor directives, keyword matching, and symbol tables. |
| **C Expression Trees** | `c/c01.c` | Implements AST (Abstract Syntax Tree) nodes for operators, handling assignments, pointer dereferencing, and arithmetic expressions. |
| **C Type System & Symbol Resolution** | `c/c02.c` | Type evaluation routines handling early C primitive types (`int`, `char`, pointers, arrays, and nascent struct support). |
| **C Statement Code Generator** | `c/c03.c` | Control flow generation for `if`, `while`, `for`, `switch`, and function return sequences. |
| **PDP-11 Code Generator (Pass 1)** | `c/c10.c` | Pass 1 code generation engine translating intermediate parse trees directly into PDP-11 machine code patterns and register moves. |
| **Assembly Optimizer & Output** | `c/c11.c` | Emits optimized PDP-11 assembly text, performing jump optimizations and register allocation. |
| **Historic Pipe System Call Specification** | `man/man2/pipe.2` | The original manual page for `pipe(II)` (dated 1/15/73): defines system call 42, explaining buffered process interconnection and how the shell connects linear process arrays. |
| **First Yacc Parser Generator Manual** | `man/man1/yacc.1` | Stephen C. Johnson's initial documentation for **Yacc** (Yet Another Compiler-Compiler), which became standard across computing. |
| **Original Crypt Utility** | `man/man1/crypt.1` | First documentation of the standard file encryption command using a simulated rotor machine. |
| **Early C Compiler Specification** | `man/man1/cc.1` | Documents the early C compiler driver, flags (`-c`, `-p`), and the runtime components `/lib/c[01]` and `/lib/crt0.o`. |

## Recommended Exploration Path

To understand the Third Edition milestone:

1. **Read the Historic Pipe Specification:**
   Start by reading `man/man2/pipe.2`. Observe how McIlroy and Thompson formalized IPC buffering (504 bytes) and how the shell was adapted to spawn chained pipelines.
2. **Explore Early C Compiler Construction:**
   Study Dennis Ritchie’s compiler front-end in `c/c00.c` and expression evaluation in `c/c01.c`. Observe how concise Ritchie’s recursive-descent parsing and AST construction was.
3. **Trace PDP-11 Assembly Code Generation:**
   Examine `c/c10.c` and `c/c11.c` to understand how the compiler targeted the 8 general-purpose registers (`r0`–`r7`) of the PDP-11.
4. **Survey the Evolving Unix Userland:**
   Explore manual pages in `man/man1/` to discover newly introduced tools like `yacc`, `crypt`, and `cmp`.
