# V7 Source Code Archive

## Historical Overview
- **Release / Snapshot Date:** January 1979
- **Authors & Key Contributors:** Ken Thompson, Dennis Ritchie, Stephen R. Bourne, Brian W. Kernighan, Alfred V. Aho, Peter J. Weinberger, Stuart I. Feldman, Stephen C. Johnson, Michael E. Lesk, and Bell Telephone Laboratories researchers.
- **Target Machine Architecture:** DEC PDP-11 (specifically the PDP-11/45 and PDP-11/70 with 22-bit physical addressing and separate Instruction & Data spaces) and the 32-bit Interdata 8/32 (the pioneering portability target).
- **Historical Milestones:**
  - **The Father of Modern Unix ("The Last True Unix"):** Seventh Edition is universally celebrated as the definitive peak of Research Unix. It is the direct common ancestor of every modern Unix and Unix-like operating system: UC Berkeley branched V7 to create 3BSD and 4BSD, while AT&T branched V7 to create System III and System V.
  - **The Bourne Shell (`sh`):** Stephen Bourne introduced the revolutionary Bourne Shell (`usr/src/cmd/sh/`), introducing structured control flow (`if/then/else/fi`, `for`, `while`, `case`), functions, parameter expansion, here-documents (`<<`), and environment variable passing. Bourne famously used C macros in `mac.h` to write C in an Algol-68 style.
  - **Standard C I/O Library (`stdio.h`):** Finalized the modern Standard I/O library interface (`FILE`, `fopen`, `fread`, `fwrite`, `printf`, `stdin`, `stdout`, `stderr`), creating the portable programming standard used worldwide today.
  - **Dawn of Iconic Unix Software:** Introduced an extraordinary suite of standard tools:
    - **`awk`**: Pattern scanning language by Aho, Weinberger, and Kernighan.
    - **`make`**: The first automated software build tool by Stuart Feldman.
    - **`sed`**: The stream editor by Lee McMahon.
    - **`tar`**: Tape archive format replacing `tp`.
    - **`uucp`**: Unix-to-Unix Copy system by Mike Lesk for networked communications and early email.
    - **`f77`**: Full Fortran 77 compiler by Stuart Feldman.
    - **`lint` & `pcc`**: Static C analysis tool and the Portable C Compiler by Stephen C. Johnson.
  - **Source Provenance:** Sourced from the official Bell Laboratories Seventh Edition distribution tapes, preserved by TUHS.

## Directory Tree & Navigation Map

```
V7/
├── bin/              [Installed utility scripts (pcc, lint, diff3, nohup...)]
├── dev/              [Device construction script (makefile)]
├── etc/              [System config and administration (group, passwd, rc, ttys)]
└── usr/              [Main system and development tree]
    ├── dict/         [System dictionary wordlists (words, papers)]
    ├── doc/          [Extensive documentation and classic Bell Labs papers]
    ├── games/        [Recreational software (ching, quiz...)]
    ├── include/      [Standard C library headers (stdio.h, ctype.h, errno.h...)]
    ├── lib/          [System libraries, learn scripts, and macro packages]
    ├── man/          [Complete Seventh Edition Programmer's Manual (man0 - man8)]
    ├── mdec/         [PDP-11 bootstrap records (hpuboot.s, rpuboot.s)]
    ├── pub/          [Ascii and troff character tables]
    ├── spool/        [Spool queues (at, mail, secretmail)]
    ├── src/          [Complete operating system and userland source code]
    │   ├── cmd/      [Standard commands (sh/, awk/, make/, sed/, tar/, uucp/...)]
    │   ├── libc/     [Complete C standard library (stdio/, gen/, sys/, crt/)]
    │   ├── libdbm/   [Ken Thompson's original DBM key-value database]
    │   ├── libF77/   [Fortran 77 runtime support]
    │   └── games/    [Game sources]
    └── sys/          [The V7 operating system kernel]
        ├── 40/       [PDP-11/40 non-split I/D adaptations]
        ├── conf/     [System build configuration (low.s, mch.s)]
        ├── dev/      [Hardware device drivers and buffer cache]
        ├── h/        [Kernel internal headers (param.h, proc.h, user.h...)]
        └── sys/      [Architecture-independent kernel algorithms]
```

## Key Source Code Files

| Component / Subsystem | File Link | Description |
| :--- | :--- | :--- |
| **The Bourne Shell** | `usr/src/cmd/sh/` | Stephen Bourne's complete shell: `main.c`, `cmd.c`, `xec.c` (command execution engine), and `mac.h` (Algol-68 preprocessor macros). |
| **Standard I/O Header & Library** | `usr/include/stdio.h`, `usr/src/libc/stdio/` | The historic definition of `struct _iobuf`, `stdin`, `stdout`, `stderr`, `BUFSIZ`, and standard buffered I/O functions. |
| **Make Build Automation** | `usr/src/cmd/make/` | Stuart Feldman's original implementation of **`make`**, parsing dependency graphs, timestamps, and executing shell actions. |
| **Awk Pattern Scanner** | `usr/src/cmd/awk/` | Original implementation of `awk` by Aho, Weinberger, and Kernighan (`awk.g.y`, `awk.lx.l`). |
| **Sed Stream Editor** | `usr/src/cmd/sed/` | Lee McMahon's stream editor performing non-interactive regex filtering and transformations. |
| **Kernel Entry & Process 0** | `usr/sys/sys/main.c` | Kernel initialization: memory probing, mounting rootdev, clearing core, and executing `/etc/init`. |
| **Process Scheduler & Context Switching** | `usr/sys/sys/slp.c` | Multiprogramming engine: `sleep()`, `wakeup()`, `sched()`, and process priority re-computation. |
| **Pathname Traversal (`namei`)** | `usr/sys/sys/nami.c` | Path resolution: parses directory structures on disk, checks permissions, and handles root, current, and parent directory paths. |
| **Buffer Cache Subsystem** | `usr/sys/dev/bio.c` | Block I/O buffer management: `bread()`, `bwrite()`, `getblk()`, and asynchronous I/O completion. |
| **Kernel Header Structures** | `usr/sys/h/param.h`, `usr/sys/h/user.h`, `usr/sys/h/proc.h` | Definitions for fundamental kernel constants (`NPROC`, `NBUF`), `struct user` (`u.` area), and `struct proc`. |
| **Key-Value Store (DBM)** | `usr/src/libdbm/` | Ken Thompson's original DBM hash-based database library (`dbm.c`), the direct ancestor of NDBM, GDBM, and Berkeley DB. |
| **Hardware Drivers** | `usr/sys/dev/hp.c`, `usr/sys/dev/tty.c` | Drivers for RP04/RP05/RP06 moving-head disk packs and asynchronous terminal lines. |

## Recommended Exploration Path

To understand the bedrock upon which modern Unix was constructed:

1. **Examine the Foundation of Standard C:**
   Open `usr/include/stdio.h` and browse the implementation in `usr/src/libc/stdio/`. Observe how clean, simple, and elegant the original standard I/O library was.
2. **Dive into the Bourne Shell:**
   Explore `usr/src/cmd/sh/`. Start with `mac.h` to appreciate Bourne's Algol syntax macros, then follow command execution in `xec.c`.
3. **Trace the V7 Kernel Subsystems:**
   Read `usr/sys/h/param.h` and `usr/sys/h/user.h`. Then trace the boot sequence in `usr/sys/sys/main.c` and scheduler in `usr/sys/sys/slp.c`.
4. **Follow Path Traversal and Inode Lifecycle:**
   Inspect `usr/sys/sys/nami.c` and `usr/sys/sys/iget.c`.
5. **Study the Inception of Classic Tools:**
   Read Stuart Feldman's `usr/src/cmd/make/main.c` to see how dependency tracking was first implemented.
