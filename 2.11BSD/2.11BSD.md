# 2.11BSD Source Code Archive

## Historical Overview
- **Release Date:** December 1991 (with continuous community patch maintenance into the late 1990s).
- **Key Developers:** Steven Schultz, Keith Bostic, Michael J. Karels, Kirk McKusick.
- **Machine Architecture:** DEC PDP-11 with separate Instruction/Data (I/D) space (PDP-11/44, 45, 53, 70, 73, 83, 84, 93, 94).
- **Historical Milestones:**
  - 2.11BSD represents the **culmination and ultimate zenith of PDP-11 UNIX engineering**.
  - Faced with the rigid 16-bit PDP-11 architectural constraint (64KB I + 64KB D space), Steven Schultz and Keith Bostic performed an engineering miracle: backporting almost the entirety of **4.3BSD** into the PDP-11 kernel.
  - **Full TCP/IP Stack on 16-bit Hardware:** Backported the complete 4.3BSD Berkeley TCP/IP networking stack (`sys/netinet`, `sys/net`) to PDP-11, operating either in kernel space or in supervisor mode overlays.
  - **Modernized Filesystem:** Integrated 4.3BSD filesystem layout, long filenames, fast symbolic links, and `/dev/klog` kernel logging daemon.
  - Included a complete 4.3BSD userland: modern networking daemons (`ftpd`, `telnetd`, `routed`), user tools (`vi`, `csh`), and full ANSI C compiler support.

## Directory Tree & Navigation Map
```
2.11BSD/
├── sys/             # Complete 2.11BSD kernel source tree
│   ├── pdp/         # PDP-11 machine-dependent assembly, MMU, and trap code
│   ├── pdpif/       # PDP-11 network interface drivers (DEQNA, DELQA, etc.)
│   ├── pdpuba/      # UNIBUS and Q-bus device drivers (disks, tapes, serial lines)
│   ├── sys/         # Core machine-independent kernel routines
│   ├── netinet/     # Full TCP/IP network protocol stack
│   ├── net/         # Generic network interface routing and socket layers
│   ├── netns/       # Xerox XNS protocol implementation
│   ├── conf/        # Kernel configuration definitions and build scripts
│   ├── autoconfig/  # Hardware probe and dynamic configuration program
│   ├── pdpstand/    # Standalone bootloaders and disk formatters
│   └── GENERIC/     # Pre-configured generic kernel build directory
├── src/             # Complete userland source tree
│   ├── bin/         # Standard system commands (sh, ls, cp, etc.)
│   ├── sbin/        # System administration binaries (init, fsck, mount, route)
│   ├── ucb/         # Berkeley userland tools (vi, csh, Mail, rdist, tftp)
│   ├── usr.bin/     # Userland utilities (make, yacc, lex, awk, etc.)
│   ├── usr.sbin/    # Network and system daemons (inetd, ftpd, telnetd, routed)
│   ├── libexec/     # System helper daemons and execution wrappers
│   ├── etc/         # System administrative scripts and tables
│   ├── lib/         # C runtime libraries, mathematical libraries, termcap
│   └── share/       # Architecture-neutral data (tmac, man, fontinfo)
├── include/         # System header files (<sys/*.h>, <arpa/*.h>, etc.)
├── man/             # Complete manpages across sections 1 through 8
├── doc/             # System documentation, SMM (System Manager's Manual), USD, PS1
└── etc/, bin/, sbin/ # Root file system binaries and administration files
```

## Key Source Code Files
| File Path | Description & Architectural Significance |
| :--- | :--- |
| `sys/pdp/locore.s` | PDP-11 assembly entry point: hardware bootstrap, MMU setup, interrupt service routines, and context switching. |
| `sys/sys/init_main.c` | Kernel bootstrap: initializes buffer cache, mounts root, and forks process 1 (`/sbin/init`). |
| `sys/sys/init_sysent.c` | System call dispatch table mapping 4.3BSD system call numbers to handlers. |
| `sys/pdp/machdep.c` | PDP-11 memory management, segment register allocation, and machine-dependent traps. |
| `sys/netinet/tcp_input.c` | Full 4.3BSD TCP packet receiver squeezed into PDP-11 memory. |
| `sys/netinet/ip_input.c` | IP packet decoding, routing, and checksum verification. |
| `sys/sys/ufs_alloc.c` | Fast File System block allocation ported to 16-bit PDP-11 disk structures. |
| `sys/sys/ufs_inode.c` | Inode lookup, locking, reading, and truncation logic. |
| `src/ucb/vi/` | Complete 2.11BSD vi text editor source. |

## Recommended Exploration Path
1. **Examine the 16-Bit MMU & Overlay Architecture (`sys/pdp/`):**
   - Start with `sys/pdp/locore.s` to see how PDP-11 APR registers are used to switch memory windows between supervisor mode, user space, and kernel overlays.
2. **Trace System Startup (`sys/sys/init_main.c`):**
   - Follow `init_main.c` to observe device initialization and the startup of `/sbin/init`.
3. **Study Squeezed TCP/IP Networking (`sys/netinet/`):**
   - Inspect `sys/netinet/tcp_input.c` and `sys/netinet/ip_input.c` to see how the full BSD networking stack was made to function inside a 16-bit machine.
4. **Review Userland Daemons (`src/usr.sbin/`):**
   - Look at `src/usr.sbin/inetd/inetd.c` and `src/usr.sbin/routed/` to see how modern internet daemons ran on the PDP-11.
