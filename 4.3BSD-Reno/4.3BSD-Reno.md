# 4.3BSD-Reno Source Code Archive

## Historical Overview
- **Release Date:** June 1990
- **Key Developers:** Kirk McKusick, Michael J. Karels, Keith Bostic, Rick Macklem (NFS), CSRG.
- **Machine Architecture:** DEC VAX, CCI Tahoe, HP 9000/300 (Motorola 68020/68030 `hp300`), and early Intel 80386 (`i386`).
- **Historical Milestones:**
  - Named after Reno, Nevada—the CSRG considered this release "a gamble" due to the enormous volume of new, untried architectural code.
  - **Introduction of the Virtual Filesystem (`vnode`) Layer:** Modeled on Sun's VFS architecture, CSRG decoupled filesystem implementations from the kernel file descriptor table (`src/sys/kern/vfs_*.c`), enabling multiple heterogeneous filesystems to coexist.
  - **Client/Server NFS Implementation:** Integrated Rick Macklem's independent, clean-room implementation of Sun's Network File System (NFS), avoiding SunOS licensing contamination (`src/sys/nfs/`).
  - **HP 9000/300 & Early Intel 386 Support:** Expanded hardware support to Motorola 68000 workstations (`hp300`) and the emerging Intel 386 PC architecture (`i386`).
  - **OSI / ISO Networking:** Added a complete ISO networking protocol suite (`netiso/`), including TP4 and CLNP.
  - **Modernized Directory Structure:** Reorganized the entire BSD source tree into its modern structure under `src/` (`src/sys`, `src/bin`, `src/sbin`, `src/usr.bin`, `src/usr.sbin`, `src/share`).
  - **POSIX.1 Compliance:** Added POSIX session management, job control, and ANSI C library interfaces.

## Directory Tree & Navigation Map
```
4.3BSD-Reno/
├── bin/             # Root binary utilities (sh, csh, ls, ed)
├── sbin/            # Essential system administration commands (init, fsck, mount)
├── libexec/         # System execution wrappers
├── share/           # Architecture-independent data (man, doc, dict, skel)
├── include/         # System header files (<sys/*.h>, <arpa/*.h>, <rpc/*.h>)
├── games/           # BSD games suite
├── contrib/         # User contributed packages (MH mail, etc.)
├── old/             # Obsolete utilities kept for backward compatibility
└── src/             # Complete 4.3BSD-Reno unified source tree
    ├── sys/         # Reno multi-architecture operating system kernel
    │   ├── kern/       # Machine-independent kernel routines & VFS layer (vfs_*.c)
    │   ├── ufs/        # Berkeley Fast File System adapted to the vnode layer
    │   ├── nfs/        # Rick Macklem's BSD client and server NFS implementation
    │   ├── hp300/      # HP 9000/300 (Motorola 68020/68030) machine support
    │   ├── i386/       # Early Intel 80386 PC machine support
    │   ├── tahoe/      # CCI Tahoe processor support
    │   ├── vax/        # DEC VAX processor support
    │   ├── netinet/    # TCP/IP protocol suite
    │   ├── netiso/     # ISO OSI protocol suite (TP4, CLNP, ES-IS)
    │   ├── netns/      # Xerox Network Systems (XNS) protocol suite
    │   ├── net/        # Generic network interface routing and sockets
    │   └── conf/       # Kernel configuration rules
    ├── bin/         # Standard system commands source
    ├── sbin/        # System administration commands source
    ├── usr.bin/     # Userland utilities source
    ├── usr.sbin/    # System daemons source (inetd, ftpd, routed, nfsd)
    ├── libexec/     # Daemon helpers and wrapper binaries
    ├── lib/         # C runtime libraries, math, termcap
    └── share/       # Documentation, manpages, and roff macros
```

## Key Source Code Files
| File Path | Description & Architectural Significance |
| :--- | :--- |
| `src/sys/kern/vfs_subr.c` | Core Berkeley Virtual Filesystem (VFS) operations, vnode allocation, and locking. |
| `src/sys/kern/vfs_vnops.c` | Generic vnode operation dispatchers (`vn_open`, `vn_read`, `vn_write`, `vn_close`). |
| `src/sys/ufs/ufs_vfsops.c` | Fast File System mount, unmount, and superblock management under the VFS layer. |
| `src/sys/nfs/nfs_vfsops.c` | Rick Macklem's NFS mount, RPC client setup, and transaction engine. |
| `src/sys/nfs/nfs_serv.c` | In-kernel NFS server request processing and file handle validation. |
| `src/sys/hp300/locore.s` | Motorola 68030 assembly bootstrap, MMU page table setup, and trap handlers. |
| `src/sys/i386/locore.s` | Early Intel 80386 protected-mode bootstrap and GDT/IDT descriptor setup. |
| `src/sys/netiso/tp_input.c` | ISO Transport Protocol Class 4 (TP4) packet receiver. |

## Recommended Exploration Path
1. **Study the VFS / Vnode Abstraction (`src/sys/kern/`):**
   - Read `src/sys/kern/vfs_subr.c` and `vfs_vnops.c` to see how BSD decoupled file descriptors from disk structures.
2. **Inspect Clean-Room NFS (`src/sys/nfs/`):**
   - Read `src/sys/nfs/nfs_vfsops.c` and `nfs_serv.c` to see how Rick Macklem built a high-performance NFS client/server from protocol specifications.
3. **Examine Motorola 68000 & Intel 386 Hardware Support:**
   - Trace Motorola 68030 startup in `src/sys/hp300/locore.s` and Intel 386 protected mode entry in `src/sys/i386/locore.s`.
4. **Review Modernized Userland Structure (`src/`):**
   - Notice how all userland source code is cleanly separated into `bin/`, `sbin/`, `usr.bin/`, and `usr.sbin/`.
