# V5 Source Code Archive

## Historical Overview
- **Release / Snapshot Date:** June 1974 (Kernel files dated late 1974 / early 1975).
- **Authors & Key Contributors:** Ken Thompson, Dennis Ritchie, with contributions from Bell Telephone Laboratories researchers.
- **Target Machine Architecture:** DEC PDP-11 (primarily PDP-11/40 with 18-bit memory addressing and no separate Instruction and Data spaces; kernel binary size was approximately 26 KB).
- **Historical Milestones:**
  - **The Academic Distribution Watershed:** Fifth Edition was the first version of Unix licensed and distributed broadly to universities and educational institutions by AT&T for a nominal media handling fee. This sparked the worldwide academic adoption of Unix that led to BSD, GNU, and Linux.
  - **Maturity of the C Kernel:** The rewrite in C that began in V4 was consolidated and stabilized in V5. The codebase exhibits cleaner abstractions, modular separation, and native support for pipes (`pipe.c`), swap devices, and process multiplexing.
  - **Early Tools Landscape:** At this junction, neither the Standard I/O library (`stdio.h`) nor Steve Bourne’s shell existed. Applications directly invoked system calls or primitive I/O routines, and userland code was divided into organized partitions (`usr/source/s1` through `s7`).
  - **Source Provenance:** Preserved from `v5root.tar.gz`, donated by Dennis Ritchie to the Unix Heritage Society (TUHS).

## Directory Tree & Navigation Map

```
V5/
├── etc/              [System configuration, user accounts, and initialization]
│   ├── passwd        [Historic password database]
│   ├── rc            [Boot initialization script]
│   └── ttys          [Terminal line configuration]
└── usr/              [Main userland and system root]
    ├── c/            [Dennis Ritchie's C compiler (c00.c - c13.c, cvopt.c)]
    ├── fort/         [Early Fortran runtime support]
    ├── lib/          [System libraries and character translation tables]
    ├── mdec/         [PDP-11 bootstrap loaders (rkf.s, tboot.s, uboot.s)]
    ├── pub/          [Public character set maps (ascii, kbd)]
    ├── source/       [Complete command source code divided into s1, s2, s3, s4, s7]
    └── sys/          [Complete C operating system kernel source]
        ├── *.h       [Kernel headers (buf, file, inode, param, proc, user...)]
        ├── conf/     [Hardware configuration and low-level PDP-11 vectors]
        ├── dmr/      [Dennis Ritchie's device drivers and buffer cache]
        └── ken/      [Ken Thompson's scheduler, memory, syscalls, and IPC]
```

## Key Source Code Files

| Component / Subsystem | File Link | Description |
| :--- | :--- | :--- |
| **Pipes Implementation in C** | `usr/sys/ken/pipe.c` | The complete, authentic C implementation of pipes: allocates an anonymous disk inode, manages reader/writer synchronization (`readp()`, `writep()`), pipe locking (`plock()`, `prele()`), and 4096-byte circular buffering. |
| **Kernel Bootstrap & Process 0** | `usr/sys/ken/main.c` | Core initialization routine `main()`: zeroes memory, clears core maps, sets up `proc[0]`, mounts root, and initializes `/etc/init`. |
| **Process Scheduler & Sleep Engine** | `usr/sys/ken/slp.c` | The heartbeat of Unix multitasking: `sleep()`, `wakeup()`, `sched()`, and process priority calculation. |
| **System Call Dispatcher** | `usr/sys/ken/sysent.c` | Jump table mapping system call numbers to functions (`sysfork`, `sysread`, `syswrite`, `syspipe`, `sysexec`). |
| **Pathname Traversal Engine** | `usr/sys/ken/nami.c` | Pathname lookup function `namei()`: walks directory entries on disk to locate inode numbers matching requested path strings. |
| **Inode Allocation & Caching** | `usr/sys/ken/iget.c`, `usr/sys/ken/alloc.c` | Inode lifecycle routines (`iget`, `iput`, `ialloc`, `ifree`) and filesystem super-block block allocators. |
| **Buffer Cache Subsystem** | `usr/sys/dmr/bio.c` | Block I/O buffer management: `bread()`, `bwrite()`, asynchronous read-ahead (`breada`), and LRU cache buffer recycling. |
| **TTY Device Driver** | `usr/sys/dmr/tty.c` | Teletype character handling, raw/cooked modes, erase/kill processing, and circular clist queuing. |
| **Disk Drivers** | `usr/sys/dmr/rk.c`, `usr/sys/dmr/rp.c` | Hardware drivers for the DEC RK05 cartridge disk and RP03 disk packs. |
| **Dennis Ritchie's C Compiler** | `usr/c/c00.c` – `usr/c/c13.c` | Full source code of the V5 C compiler, including frontend parser passes (`c0*.c`) and code generators (`c1*.c`). |
| **Userland Commands** | `usr/source/s1/`, `usr/source/s2/` | Canonical user utilities written in C: `cat.c`, `cp.c`, `ls.c`, `grep.c`, `mkdir.c`, `rm.c`, `login.c`, and early `sh/`. |
| **Boot Block Loaders** | `usr/mdec/rkf.s`, `usr/mdec/tboot.s` | PDP-11 cold-boot assembly code loaded into sector 0 to read the kernel binary into memory from tape or disk. |

## Recommended Exploration Path

To master the Fifth Edition codebase:

1. **Inspect the C Pipe Implementation:**
   Start with `usr/sys/ken/pipe.c`. It is one of the cleanest, most concise implementations of IPC in systems history.
2. **Follow Process Creation and Execution:**
   Read `usr/sys/ken/sys1.c` (`fork()`, `exec()`, `wait()`, `exit()`), and trace how process state transitions through `usr/sys/ken/slp.c`.
3. **Trace Inode and Path Operations:**
   Follow `namei()` in `usr/sys/ken/nami.c` and `iget()`/`iput()` in `usr/sys/ken/iget.c`.
4. **Examine the Block Buffer Cache:**
   Read `usr/sys/dmr/bio.c` to observe how asynchronous I/O and block buffer pools were structured.
5. **Browse the Userland Commands:**
   Open `usr/source/s1/cat.c` and `usr/source/s2/ls.c` to see early C command structures before standard library headers were standardized.
