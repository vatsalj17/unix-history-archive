# V10 Source Code Archive

## Historical Overview
- **Release / Snapshot Date:** October 1989 (Manual Volumes 1 & 2 published 1990).
- **Authors & Key Contributors:** Ken Thompson, Dennis Ritchie, Douglas McIlroy, Brian W. Kernighan, Rob Pike, Dave Presotto, Peter J. Weinberger, Tom Duff, Norman Wilson, Howard Trickey, Gerard J. Holzmann, and Bell Telephone Laboratories researchers (Computing Science Research Center, Department 1127).
- **Target Machine Architecture:** DEC VAX (VAX-11/750, VAX-11/780, VAX 8550, VAX 8650, MicroVAX) with cross-compilation and experiments targeting MIPS and AT&T CRISP/Hobbit; graphical display on AT&T 630 MTG / Teletype 5620 terminals.
- **Historical Milestones:**
  - **The Grand Finale of Research Unix:** Tenth Edition was the final release of Bell Labs Research Unix, marking the culmination of two decades of operating system development (1969–1989).
  - **The Direct Bridge to Plan 9 from Bell Labs:** During the development of V10, the core Bell Labs research team was already designing the next-generation distributed operating system: **Plan 9 from Bell Labs**. As a result, V10 served as the primary incubator for Plan 9 technology:
    - **`rc`**: Tom Duff's clean, modern shell (`cmd/rc/`), replacing complex Bourne syntax with clean list-oriented semantics.
    - **`mk`**: Andrew Hume's successor to `make`, resolving subtle dependency evaluation issues.
    - **`sam`**: Rob Pike's multi-window structural regular expression text editor.
    - **`pico`**: Gerard Holzmann's image processing language.
    - **`fshare` & `netfs`**: Network file sharing and remote namespace mounting (`netfs/`).
  - **Complete Maturity of Streams & `/proc`:** Streams character I/O and Tom Killian's `/proc` filesystem reached full maturity in the V10 kernel, providing an entirely unified model for networking, terminal I/O, and process debugging.
  - **Multimedia & Graphics Integration:** Includes AT&T 630 Multi-Tasking Graphics support (`630/`), raster graphics manipulation (`libpicfile/`), and vector font engines (`libj/`).
  - **Source Provenance:** Preserved from `v10src.tar.bz2`, donated by Dan Cross to the Unix Heritage Society (TUHS).

## Key Source Code Files

| Component / Subsystem | File Link | Description |
| :--- | :--- | :--- |
| **Tom Duff's `rc` Shell** | `cmd/rc/` | The complete source code of the `rc` shell, featuring clean list variables, pattern matching, simplified control flow, and concise parsing. |
| **Andrew Hume's `mk` Build Engine** | `cmd/mk/` | The modern dependency-tracking build system designed to replace `make`, introducing regular expression rules and clean shell integration. |
| **Rob Pike's `sam` Editor** | `cmd/sam/` | Multi-window bitmap text editor with structural regular expressions, client/server split architecture, and mouse interaction. |
| **V10 Kernel Entry & Initialization** | `sys/sys/main.c` | 32-bit VAX initialization: memory sizing, Streams queue initialization, `/proc` registration, root filesystem mounting, and process 0 setup. |
| **Kernel Streams Engine** | `sys/sys/stream.c` | Dennis Ritchie's fully matured Streams subsystem handling bidirectional message passing, flow control, and dynamic module plumbing. |
| **Mature `/proc` Implementation** | `sys/sys/proca.c` | High-performance `/proc` filesystem driver providing memory mapping, breakpoint control, and process debugging via regular filesystem calls. |
| **VAX Demand Paging Virtual Memory** | `sys/vm/` | Demand-paged virtual memory algorithms managing page tables, working sets, copy-on-write page faults, and page clustering. |
| **Image Processing Library** | `libpicfile/` | Gerard Holzmann’s image processing routines for raster image formats, pixel packing/unpacking, and graphics channel manipulation. |
| **Distributed Filesystem Daemons** | `netfs/serv/`, `netfs/libnetb/` | Dave Presotto's distributed file server daemons providing remote filesystem access and namespace mapping. |
| **Volume 2 Research Papers** | `vol2/` | Full machine-readable troff source documents of foundational computing papers by Ritchie, Thompson, Pike, Kernighan, Bentley, and Presotto. |

## Recommended Exploration Path

To study the zenith of Research Unix and the birthplace of Plan 9:

1. **Study the Evolution of the Unix Shell (`rc`):**
   Explore `cmd/rc/`. Compare Tom Duff’s clean, list-based parser and execution model with the earlier Bourne shell (`sh`) from V7.
2. **Examine Modern Build Automation (`mk`):**
   Read `cmd/mk/`. Notice how Andrew Hume redesigned rules and pattern matching to overcome the syntactic quirks of `make`.
3. **Trace Streams & `/proc` in the Kernel:**
   Read `sys/sys/stream.c` and `sys/sys/proca.c` to understand how the mature kernel unified character I/O and process debugging.
4. **Explore Early Plan 9 Filesystem Concepts:**
   Examine `netfs/` and `makefile` to see how file sharing and remote namespace mounting evolved before 9P was formally established.
5. **Read the Classic Volume 2 Papers:**
   Browse the troff sources in `vol2/` to read firsthand papers authored by Ken Thompson, Dennis Ritchie, and Rob Pike reflecting on 20 years of Unix research.
