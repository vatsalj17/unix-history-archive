# 4.2BSD Source Code Archive

## Historical Overview
- **Release Date:** August / September 1983
- **Key Developers:** Bill Joy, Sam Leffler, Kirk McKusick, Eric Allman, Michael J. Karels, Computer Systems Research Group (CSRG).
- **Machine Architecture:** DEC VAX (VAX-11/780, VAX-11/750, VAX-11/730).
- **Historical Milestones:**
  - 4.2BSD is widely recognized as **one of the most influential operating systems ever created**, fundamentally shaping the architecture of modern computing and the global Internet.
  - **The Berkeley Sockets API:** Officially introduced the socket abstraction (`socket()`, `bind()`, `connect()`, `listen()`, `accept()`, `send()`, `recv()`), creating the universal programming interface for network communication that remains standard across all modern operating systems (Linux, Windows, macOS, BSD).
  - **Production Kernel TCP/IP:** Integrated the first battle-tested, kernel-level implementation of the TCP/IP protocol suite (IPv4, TCP, UDP, ICMP, ARP), cementing TCP/IP as the foundation of the Internet.
  - **Berkeley Fast File System (FFS):** Kirk McKusick's groundbreaking filesystem officially debuted, offering a 10x throughput improvement over traditional UNIX filesystems via cylinder groups, block allocation optimizations, and fragments.
  - **Modern Signal System:** Implemented reliable signals and atomic signal masks (`sigvec`, `sigsetmask`, `sigpause`).
  - **Comprehensive Network Services:** Introduced the standard suite of network utilities and daemons: `rsh`, `rlogin`, `rcp`, `rwho`, `routed` (RIP routing daemon), `ftpd`, `telnetd`, and Eric Allman's `sendmail` (replacing delivermail).

## Directory Tree & Navigation Map
```
4.2BSD/
├── bin/             # Essential root utilities (sh, csh, ed)
├── dev/             # Device special node creation script (MAKEDEV)
├── etc/             # Administrative utilities, network config, daemon launchers
├── usr/             # System hierarchy
│   ├── src/         # Complete 4.2BSD source tree
│   │   ├── sys/     # The historic 4.2BSD VAX kernel source
│   │   │   ├── sys/        # Core kernel, socket IPC (uipc_*.c), FFS (ufs_*.c)
│   │   │   ├── netinet/    # Landmark Berkeley TCP/IP networking stack
│   │   │   ├── net/        # Core network routing, interfaces, packet buffers
│   │   │   ├── netimp/     # ARPANET IMP interface drivers
│   │   │   ├── netpup/     # Xerox PARC PUP protocol suite
│   │   │   ├── vax/        # Machine-dependent VAX assembly, MMU, and traps
│   │   │   ├── vaxuba/     # UNIBUS device drivers
│   │   │   ├── vaxmba/     # MASSBUS device drivers
│   │   │   ├── conf/       # Kernel configuration generator (config)
│   │   │   └── stand/      # VAX standalone bootloaders and disk formatters
│   │   ├── ucb/     # Berkeley commands (vi, csh, netstat, dbx, rlogin)
│   │   ├── bin/     # Standard system commands (ls, cp, sh, make)
│   │   ├── etc/     # Network daemons (routed, ftpd, telnetd)
│   │   ├── usr.lib/ # Language libraries, runtime objects, sendmail source
│   │   ├── lib/     # C runtime library, math library, curses
│   │   └── games/   # BSD games suite (rogue, trek)
│   ├── include/     # Standard system headers (<sys/socket.h>, <netinet/in.h>)
│   ├── doc/         # Technical reports (McKusick FFS paper, Leffler IPC guide)
│   └── man/         # Section 1 through 8 manual pages
```

## Key Source Code Files
| File Path | Description & Architectural Significance |
| :--- | :--- |
| `usr/src/sys/sys/uipc_socket.c` | **The Berkeley Sockets API:** Production implementation of socket system calls (`socreate`, `sobind`, `soconnect`, `sodisconnect`). |
| `usr/src/sys/sys/uipc_socket2.c` | Internal socket state machine, socket buffer flow control, and data queuing. |
| `usr/src/sys/netinet/tcp_input.c` | TCP state transition logic, sequence number validation, and acknowledgment processing. |
| `usr/src/sys/netinet/tcp_output.c` | TCP packet construction, window size computation, and transmission. |
| `usr/src/sys/netinet/ip_input.c` | IPv4 datagram handling, option parsing, checksum verification, and forwarding. |
| `usr/src/sys/sys/ufs_alloc.c` | Kirk McKusick's Fast File System cylinder group block allocation algorithms. |
| `usr/src/sys/sys/ufs_inode.c` | FFS inode disk lifecycle management, block pointer resolution, and truncation. |
| `usr/src/sys/vax/locore.s` | VAX low-level bootstrap, page table registration, and system call interrupt dispatch. |
| `usr/src/etc/routed/` | Implementation of the Routing Information Protocol (RIP) daemon. |
| `usr/src/usr.lib/sendmail/` | Eric Allman's production Sendmail Internet mail router. |

## Recommended Exploration Path
1. **Master the Sockets Implementation (`usr/src/sys/sys/uipc_socket.c`):**
   - Trace `socreate()` and follow how socket descriptors link to kernel protocol switches (`usr/src/sys/sys/uipc_domain.c`).
2. **Follow a TCP Packet Through the Kernel:**
   - Begin at `usr/src/sys/netinet/ip_input.c` to see IP packet handling, then follow the packet dispatch into `usr/src/sys/netinet/tcp_input.c`.
3. **Analyze the Berkeley Fast File System (`usr/src/sys/sys/ufs_alloc.c`):**
   - Examine how cylinder groups are chosen to minimize disk head seek times during allocation.
4. **Inspect Network Daemons (`usr/src/etc/`):**
   - Examine `usr/src/etc/routed/` and `usr/src/ucb/netstat/` to see how early internet diagnostics and routing were structured.
