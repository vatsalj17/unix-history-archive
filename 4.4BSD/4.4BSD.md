# 4.4BSD Source Code Archive

## Historical Overview
- **Release Date:** June 1993 (released as 4.4BSD-Encumbered; settled in 1994 to create 4.4BSD-Lite).
- **Key Developers:** Kirk McKusick, Keith Bostic, Michael J. Karels, Computer Systems Research Group (CSRG) at UC Berkeley.
- **Machine Architecture:** Multi-platform: Intel 80386 (`i386`), HP 9000/300 (`hp300`), Sun SPARC (`sparc`), Sony NEWS (`news3400`), Omron LUNA-68K (`luna68k`), and DEC VAX (`vax`).
- **Historical Milestones:**
  - 4.4BSD was the **grand final release** of the Computer Systems Research Group at UC Berkeley, concluding over 15 years of world-changing operating system development.
  - Released during the height of the *USL v. BSDi* lawsuit, this version represents the fully-featured "Encumbered" edition before the out-of-court settlement resulted in 4.4BSD-Lite (which removed the disputed AT&T files).
  - **Complete Mach VM Integration:** Fully replaced the traditional BSD paging code with the Mach virtual memory architecture, introducing unified memory mapping (`mmap`) and memory-backed files.
  - **Stackable Virtual Filesystems (`miscfs/`):** Pioneered layered filesystem technology:
    - Union mount (`union/`): Allows layering read-write filesystems over read-only directories.
    - Portal filesystem (`portal/`): Intercepts filesystem path opens and connects them to userland services or sockets.
    - Memory filesystem (`mfs/`), Null filesystem (`nullfs/`), and User-ID mapping (`umapfs/`).
  - **Log-Structured File System (LFS):** Integrated Mendel Rosenblum and John Ousterhout's revolutionary Log-Structured File System (`ufs/lfs/`), treating the entire disk as an append-only log for maximum write performance.
  - **64-bit File Offsets:** Introduced 64-bit quad integers (`quad_t`, `off_t`) for file offsets, breaking the historic 2GB file size barrier.
  - **Full Standards Conformance:** Full compliance with IEEE POSIX 1003.1-1990 and ANSI C standards across the entire operating system.

## Key Source Code Files
| File Path | Description & Architectural Significance |
| :--- | :--- |
| `usr/src/sys/kern/init_main.c` | The final CSRG kernel entry point: initializes VM, VFS, buffer cache, threads, and forks `init`. |
| `usr/src/sys/vm/vm_map.c` | Mach virtual memory address map manager, supporting memory regions and protection flags. |
| `usr/src/sys/vm/vm_fault.c` | Production demand-paging fault handler for copy-on-write and memory-mapped files. |
| `usr/src/sys/ufs/lfs/lfs_alloc.c` | Mendel Rosenblum's Log-Structured File System (LFS) segment allocation engine. |
| `usr/src/sys/ufs/lfs/lfs_vfsops.c` | LFS mount, unmount, and checkpointing filesystem operations. |
| `usr/src/sys/miscfs/union/union_vfsops.c` | Stackable union mount filesystem, combining multiple directory hierarchies into one. |
| `usr/src/sys/miscfs/portal/portal_vfsops.c` | Portal filesystem, creating dynamic filesystem namespace links to network sockets. |
| `usr/src/sys/i386/i386/locore.s` | Mature 32-bit Intel 386 protected mode bootstrap and interrupt dispatcher. |
| `usr/src/sys/sparc/sparc/locore.s` | Sun SPARC RISC architectural bootstrap, window overflow/underflow trap handlers. |
| `usr/src/sys/net/bpf.c` | Steven McCanne & Van Jacobson's Berkeley Packet Filter (BPF) kernel engine. |

## Recommended Exploration Path
1. **Trace the Capstone Kernel Entry (`usr/src/sys/kern/init_main.c`):**
   - Follow `main()` to see the final, mature bootstrap sequence of CSRG BSD.
2. **Explore the Mach Virtual Memory Subsystem (`usr/src/sys/vm/`):**
   - Trace `vm_map.c` and `vm_fault.c` to see how BSD achieved modern virtual memory management with copy-on-write mappings.
3. **Study Experimental & Stackable Filesystems (`usr/src/sys/miscfs/` & `ufs/lfs/`):**
   - Inspect `miscfs/union/` to see how union mounts were designed.
   - Read `ufs/lfs/` to understand the Log-Structured File System architecture.
4. **Examine RISC vs. CISC Kernel Bootstraps:**
   - Compare the Intel 386 bootstrap in `usr/src/sys/i386/i386/locore.s` with the SPARC RISC window trap handler in `usr/src/sys/sparc/sparc/locore.s`.
5. **Inspect the Berkeley Packet Filter (`usr/src/sys/net/bpf.c`):**
   - See how McCanne and Van Jacobson built the in-kernel packet filtering virtual machine used by `tcpdump`.
