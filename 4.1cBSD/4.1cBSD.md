# 4.1cBSD Source Code Archive

## Historical Overview
- **Release Date:** Late 1982 / Early 1983 (Interim DARPA developer release).
- **Key Developers:** Bill Joy, Sam Leffler, Kirk McKusick, Eric Allman, Robert Elz, DARPA networking steering committee.
- **Machine Architecture:** DEC VAX (VAX-11/780, VAX-11/750).
- **Historical Milestones:**
  - 4.1cBSD was a **seminal milestone in computer history**, funded by DARPA to develop a standardized networking operating system for the fledgling ARPANET/Internet.
  - **Birth of the BSD Sockets IPC:** First full implementation of the BSD Sockets API (`socket()`, `bind()`, `connect()`, `listen()`, `accept()`), introducing protocol families and communication domains (`uipc_socket.c`).
  - **Berkeley TCP/IP Protocol Suite:** Integrated the first production Berkeley TCP/IP stack (`netinet/`), replacing BBN's preliminary implementation with a high-performance kernel networking engine.
  - **Berkeley Fast File System (FFS):** Debut of Kirk McKusick's revolutionary Fast File System (`sys/ufs_alloc.c`), introducing cylinder groups, 4KB/8KB blocks with fragments, and 10x disk throughput over traditional V7 filesystems.
  - **Note on Directory Layout:** In this archive, the complete kernel source resides in `a/sys/` because the distribution tape root partition was archived as `/dev/ra0a` (the `a` filesystem slice).

## Directory Tree & Navigation Map
```
4.1cBSD/
├── a/               # Tape root partition archive containing the complete kernel
│   └── sys/         # The 4.1cBSD operating system kernel source tree
│       ├── sys/        # Core kernel, socket IPC (uipc_*.c), FFS (ufs_*.c)
│       ├── netinet/    # Historic Berkeley TCP/IP network protocol stack
│       ├── net/        # Core network routing, interfaces (if.c), raw sockets
│       ├── netimp/     # ARPANET IMP (Interface Message Processor) driver
│       ├── netpup/     # Xerox PARC PUP protocol suite driver
│       ├── vax/        # Machine-dependent VAX assembly, MMU, and trap code
│       ├── vaxuba/     # VAX UNIBUS peripheral drivers
│       ├── vaxmba/     # VAX MASSBUS peripheral drivers
│       ├── conf/       # Kernel configuration rules and compiler (config)
│       ├── stand/      # Standalone bootloaders
│       └── GENERIC/    # Generic kernel configuration directory
├── usr/             # System userland hierarchy
│   ├── src/         # Userland source code
│   │   ├── ucb/     # Berkeley utilities (csh, vi, dbx debugger, etc.)
│   │   ├── bin/     # Standard UNIX commands
│   │   ├── etc/     # Network daemons and admin tools
│   │   ├── games/   # BSD games suite
│   │   └── lib/     # C libraries, network resolver, math
│   ├── include/     # System include files
│   ├── doc/         # Technical documentation and networking papers
│   └── man/         # Section 1 through 8 manual pages
```

## Key Source Code Files
| File Path | Description & Architectural Significance |
| :--- | :--- |
| `a/sys/sys/uipc_socket.c` | **The birth of BSD sockets:** Implementation of `socreate()`, `sobind()`, `soconnect()`, `soreceive()`, and `sosend()`. |
| `a/sys/sys/uipc_socket2.c` | Socket state transitions, queue management, and buffer management. |
| `a/sys/sys/uipc_domain.c` | Implements protocol domains (`AF_INET`, `AF_UNIX`) and communication switchboard. |
| `a/sys/netinet/tcp_input.c` | Berkeley's original TCP input processing and sequence number verification. |
| `a/sys/netinet/tcp_output.c` | TCP packet transmission and header formatting. |
| `a/sys/netinet/ip_input.c` | IP datagram reception, packet reassembly, and checksum evaluation. |
| `a/sys/sys/ufs_alloc.c` | Kirk McKusick's Fast File System cylinder group block allocator. |
| `a/sys/sys/ufs_inode.c` | FFS inode disk layout, allocation, and locking. |
| `a/sys/vax/locore.s` | VAX assembly bootstrap, system control block, and interrupt handlers. |
| `usr/src/ucb/dbx/` | The `dbx` source-level symbolic debugger. |

## Recommended Exploration Path
1. **Explore the Genesis of Sockets (`a/sys/sys/uipc_socket.c`):**
   - Read `a/sys/sys/uipc_socket.c` and `uipc_socket2.c` to see how the universal network programming API was first designed.
2. **Study the Original Berkeley TCP/IP Stack (`a/sys/netinet/`):**
   - Trace incoming packets in `a/sys/netinet/ip_input.c` and TCP connection states in `a/sys/netinet/tcp_input.c`.
3. **Inspect the Fast File System (`a/sys/sys/ufs_alloc.c`):**
   - Read `ufs_alloc.c` to see how Kirk McKusick solved the disk fragmentation and rotational latency issues of traditional UNIX.
4. **Trace VAX Low-Level Startup (`a/sys/vax/locore.s`):**
   - Follow VAX hardware initialization into `a/sys/sys/init_main.c`.
