# 4.3BSD Source Code Archive

## Historical Overview
- **Release Date:** June 1986
- **Key Developers:** Kirk McKusick, Michael J. Karels, Sam Leffler, Keith Bostic, CSRG.
- **Machine Architecture:** DEC VAX (VAX-11/780, VAX-11/750, VAX-8600, MicroVAX II).
- **Historical Milestones:**
  - Known as **"The Perfection of 4.2BSD"**: While 4.2BSD introduced revolutionary concepts (Sockets, TCP/IP, FFS), it was heavily unoptimized. 4.3BSD was an intensive, methodical tuning campaign led by Karels and McKusick.
  - **The DARPA Networking "Bake-Off":** DARPA organized a rigorous performance evaluation pitting Berkeley's TCP/IP against BBN's official reference implementation. The 4.3BSD stack demonstrated overwhelming superiority in throughput, reliability, and CPU efficiency, cementing Berkeley TCP/IP as the universal global standard.
  - **FFS Quota Subsystem:** Fully integrated disk quota management into the Fast File System (`ufs_quota.c`).
  - **Xerox Network Systems (XNS):** Integrated the complete Xerox `netns` protocol suite alongside TCP/IP.
  - **BIND (Berkeley Internet Name Domain):** Officially integrated the BIND DNS server (`named`), replacing static `/etc/hosts` files with decentralized domain name resolution.
  - Included the first official BSD distribution of the **X Window System** (X10R3) in `usr/contrib/X/`.

## Directory Tree & Navigation Map
```
4.3BSD/
├── bin/             # Root binaries (sh, csh, ed)
├── dev/             # Device special node creation script (MAKEDEV)
├── etc/             # Administrative daemons and configuration files
├── usr/             # Primary system hierarchy
│   ├── src/         # System source tree
│   │   ├── sys/     # The heavily optimized 4.3BSD VAX kernel source
│   │   │   ├── sys/        # Core kernel, socket layer, FFS with quotas
│   │   │   ├── netinet/    # Tuned, high-performance TCP/IP stack
│   │   │   ├── net/        # Core network routing, interfaces, packet buffers
│   │   │   ├── netns/      # Xerox Network Systems (XNS) protocol suite
│   │   │   ├── netimp/     # ARPANET IMP driver
│   │   │   ├── vax/        # Machine-dependent VAX assembly, MMU, and traps
│   │   │   ├── vaxuba/     # UNIBUS device drivers
│   │   │   ├── vaxmba/     # MASSBUS device drivers
│   │   │   ├── conf/       # Kernel config generator rules (config)
│   │   │   └── stand/      # Standalone VAX bootloaders
│   │   ├── ucb/     # Berkeley utilities (csh, vi, netstat, dbx, ftp)
│   │   ├── bin/     # Standard UNIX commands (sh, make, awk, sed)
│   │   ├── etc/     # Network and system daemons (named, routed, ftpd)
│   │   ├── lib/     # C library, curses, termlib, math
│   │   └── games/   # BSD games suite
│   ├── contrib/     # User-contributed software packages (X10R3, enet, etc.)
│   ├── include/     # Standard C header files
│   ├── doc/         # Technical papers and reports
│   └── man/         # Section 1 through 8 manual pages
```

## Key Source Code Files
| File Path | Description & Architectural Significance |
| :--- | :--- |
| `usr/src/sys/sys/uipc_socket.c` | Heavily optimized BSD socket layer with streamlined locking and data transfer paths. |
| `usr/src/sys/netinet/tcp_input.c` | Benchmark-winning TCP input engine, optimized for minimal CPU overhead per packet. |
| `usr/src/sys/netinet/tcp_subr.c` | TCP checksum calculation, connection reset handling, and socket binding helpers. |
| `usr/src/sys/sys/ufs_alloc.c` | Fast File System block allocator with enhanced cluster allocation. |
| `usr/src/sys/sys/ufs_quota.c` | Implementation of user and group disk quotas in the Fast File System. |
| `usr/src/sys/vax/locore.s` | Optimized VAX assembly entry point and interrupt dispatch tables. |
| `usr/src/etc/named/` | The historic BIND (Berkeley Internet Name Domain) DNS server source code. |
| `usr/contrib/X/` | Early source code for the MIT X Window System (X Version 10). |

## Recommended Exploration Path
1. **Compare TCP/IP with 4.2BSD:**
   - Compare `usr/src/sys/netinet/tcp_input.c` with 4.2BSD's version to see how Karels tuned buffer handling and sequence checking to win the DARPA bake-off.
2. **Study File System Disk Quotas (`usr/src/sys/sys/ufs_quota.c`):**
   - Follow how inode allocation and block writing enforce soft and hard resource limits.
3. **Examine Early DNS Resolution (`usr/src/etc/named/`):**
   - Trace how BIND resolved hostnames to IP addresses recursively over UDP sockets.
4. **Explore the Contributed Packages (`usr/contrib/`):**
   - Inspect early X Window System server and client code in `usr/contrib/X/`.
