# V9 Source Code Archive

## Historical Overview
- **Release / Snapshot Date:** September 1986 (Snapshot preserved: Sun-3 port around early 1987).
- **Authors & Key Contributors:** Dennis Ritchie, Ken Thompson, Rob Pike, Dave Presotto, Norman Wilson, Tom Cargill, Bjarne Stroustrup, and Bell Telephone Laboratories researchers.
- **Target Machine Architecture:** Motorola 68020 (Sun-3 series workstations: Sun 3/50 and Sun 3/75 with Sun MMU, SCSI disks, and AMD Lance Ethernet) alongside DEC VAX-11/750, VAX-11/780, and VAX 8550/8650.
- **Historical Milestones:**
  - **Research Unix on Workstations:** Ninth Edition broke free from centralized VAX minicomputers, porting Research Unix onto desktop Motorola 68020 workstations. This preserved tree (`batterpudding.tar.gz`, donated by Norman Wilson) contains the Sun-3 port derived from the VAX V9 tree.
  - **The Birth of NetB (The Direct Ancestor of Plan 9 9P):** Dave Presotto and Dennis Ritchie designed **NetB** (`netb/`), a network filesystem protocol. Rather than mounting individual remote directories statelessly like Sun's NFS, NetB mounted whole remote machine namespaces, mapped user identities across networks, and maintained connection state—establishing the design paradigm that evolved into Plan 9 from Bell Labs.
  - **The Connection Server & IPC Architecture:** Dave Presotto developed the V9 IPC framework (`ipc/`), replacing BSD sockets with Streams-based connection services, listener daemons, and dialing primitives (`cs`).
  - **The Birth of C++ (`cfront`):** Contains the historic source code of Bjarne Stroustrup's **`cfront`** (`cmd/cfront/`), the original compiler front-end that translated Stroustrup's "C with Classes" into standard C code.
  - **Ken Thompson's Fast I/O (`fio`):** Ken Thompson authored the **`fio`** library (`libc/fio/`), an ultra-fast, lightweight replacement for `stdio.h` that was later standardized in Plan 9.
  - **Windowing & The Sam Editor on X11:** Ported the Teletype 5620 Blit windowing environment and Rob Pike’s structural regular expression editor `sam` (`jtools/`) to run natively on workstation framebuffers under X11.

## Directory Tree & Navigation Map

```
V9/
├── README            [Authoritative Bell Labs Sun-3 port technical guide]
├── cmd/              [Userland commands, cfront (C++), mk, rc, adb, sam]
├── include/          [V9 C library and kernel include headers (fio.h, dk.h...)]
├── ipc/              [Presotto's IPC system, connection server, and dialers]
├── jerq/             [Teletype 5620 Blit windowing system software]
├── jtools/           [Rob Pike's sam, Cargill's pi, and Blit tools ported to X11]
├── libc/             [C standard library, featuring Thompson's fio/ library]
├── libtermlib/       [Terminal capability cursor control library]
├── netb/             [The NetB remote network filesystem server & client]
├── sys/              [The V9 operating system kernel source code]
│   ├── 3-50/, 3-75/  [Sun-3 workstation kernel configurations]
│   ├── sun/          [Motorola 68020 assembly, MMU, and vector handlers]
│   ├── sys/          [Architecture-independent kernel algorithms & Streams]
│   ├── dev/, sundev/ [Drivers (SCSI disks, Zilog serial, Lance Ethernet)]
│   ├── inet/         [TCP/IP protocol stack running over Streams]
│   ├── construct/    [Bootstrap binaries used during cross-compilation]
│   └── *.old         [Original VAX V9 code retained for diffing and history]
└── X11/              [Historic port of X11 Release 1 to Research Unix]
```

## Recommended Exploration Path

To observe the transition from classic Unix to workstation computing and Plan 9:

1. **Read the Authentic Sun-3 Guide:**
   Start with `README`. It details how Bell Labs ported V9 from the VAX to the Motorola 68020 Sun-3, explaining hardware differences, SCSI drivers, and X11 integration.
2. **Inspect the Birth of C++:**
   Explore `cmd/cfront/`. Look at how Bjarne Stroustrup implemented classes, constructors, and virtual function tables by compiling them down to C structs and functions.
3. **Examine the Precursor to Plan 9 Networking:**
   Read `netb/src/share.h` and `netb/src/main.c` to see how NetB enabled network transparent namespace mounting.
4. **Study Ken Thompson's `fio` Library:**
   Browse `libc/fio/` to understand why Thompson preferred lightweight line-buffered functions over complex standard I/O streams.
5. **Trace Streams in the Kernel:**
   Read `sys/sys/stream.c` to see the polished, mature version of Dennis Ritchie's Streams architecture.
