# 4.3BSD-Tahoe Source Code Archive

## Historical Overview
- **Release Date:** June 1988
- **Key Developers:** Kirk McKusick, Michael J. Karels, Keith Bostic, Van Jacobson (LBL).
- **Machine Architecture:** DEC VAX and CCI Power 6/32 (codenamed "Tahoe", minicomputer built by Computer Consoles Inc.).
- **Historical Milestones:**
  - 4.3BSD-Tahoe was the **critical architectural turning point where BSD became hardware-portable**.
  - **Decoupling Architecture from Kernel:** Prior to Tahoe, BSD source code was deeply intertwined with DEC VAX assembly, registers, and memory assumptions. CSRG split the kernel into clean **machine-independent (`sys/`)** and **machine-dependent (`vax/`, `tahoe/`)** directory structures.
  - **Van Jacobson's Congestion Control:** In 1986–1988, the Internet suffered catastrophic "congestion collapse", where throughput plummeted by a factor of a thousand. Van Jacobson developed his groundbreaking **TCP Slow Start, Congestion Avoidance, and Fast Retransmit algorithms** (`sys/netinet/tcp_input.c`, `tcp_cong.c`), which debuted here and saved the global Internet.
  - **Clustered Network Mbufs:** Rewrote network buffer allocation (`uipc_mbuf.c`) to support 1KB/2KB cluster pages, eliminating costly packet fragmentation copies.
  - **Standardized Disk Labels:** Introduced the `disklabel` architecture (`disklabel.h`, `subr_disklabel.c`), replacing hardcoded disk partition tables with on-disk geometry descriptions.

│   │   │   └── stand/      # Multi-architecture bootloaders

## Key Source Code Files
| File Path | Description & Architectural Significance |
| :--- | :--- |
| `usr/src/sys/tahoe/locore.s` | CCI Tahoe assembly entry point, processor status register setup, and MMU context initialization. |
| `usr/src/sys/vax/locore.s` | DEC VAX assembly bootstrap and interrupt vector dispatch. |
| `usr/src/sys/netinet/tcp_input.c` | **Van Jacobson's Congestion Control:** Implementation of Slow Start, Congestion Window (`snd_cwnd`), and Fast Retransmit. |
| `usr/src/sys/sys/uipc_mbuf.c` | Rewritten network buffer allocator supporting memory cluster pages. |
| `usr/src/sys/sys/ufs_disksubr.c` | Architecture-neutral disk partitioning and disklabel interpretation routines. |
| `usr/src/sys/kdb/kdb_machdep.c` | In-kernel interactive debugger implementation for the Tahoe processor. |
| `usr/src/sys/sys/init_main.c` | Machine-independent kernel bootstrap and process 0 initialization. |

## Recommended Exploration Path
1. **Analyze Van Jacobson's Congestion Control Algorithms:**
   - Open `usr/src/sys/netinet/tcp_input.c` and search for `snd_cwnd` (congestion window) and `snd_ssthresh` (slow start threshold) to observe the code that stabilized the Internet.
2. **Compare Machine-Dependent Layers:**
   - Compare `usr/src/sys/tahoe/locore.s` with `usr/src/sys/vax/locore.s` to understand how CSRG separated architecture-specific assembly from the kernel core.
3. **Study Clustered Mbufs (`usr/src/sys/sys/uipc_mbuf.c`):**
   - Trace how network packets larger than a single mbuf were allocated efficiently using page-sized clusters.
4. **Review Dynamic Disk Partitioning:**
   - Read `usr/src/sys/sys/ufs_disksubr.c` to see how on-disk labels replaced static partition tables.
