# 4.3BSD-UWisc Source Code Archive

## Historical Overview
- **Release Date:** January 1987
- **Key Developers:** University of Wisconsin-Madison Computer Sciences Department (Dave Cohrs, Paul Borman, et al.), building on CSRG 4.3BSD.
- **Machine Architecture:** DEC VAX (VAX-11/780, 750, 8600).
- **Historical Milestones:**
  - 4.3BSD-UWisc was a historic milestone created at the University of Wisconsin-Madison: it was the **very first 4BSD distribution to successfully integrate Sun Microsystems' Network File System (NFS 2.0) and Sun Remote Procedure Call (RPC) into the 4.3BSD kernel**.
  - While SunOS ran on Motorola 68000 workstations, major academic compute servers ran 4.3BSD on DEC VAX minicomputers. The Wisconsin team bridged this gap, allowing VAX servers and Sun workstations to share files seamlessly across campus networks.
  - Ported Sun's Yellow Pages (YP / NIS) directory service (`yp/`), providing centralized user authentication and network host maps.
  - Implemented the kernel-level Sun RPC runtime (`clnt_kudp.c`, `svc_kudp.c`), integrating it directly with BSD's socket layer.
  - Provided the blueprint that later inspired Rick Macklem's independent BSD NFS implementation.

## Directory Tree & Navigation Map
```
4.3BSD-UWisc/
├── adm/             # System accounting and administrative databases
├── bin/             # Root binaries (sh, csh, ed)
├── etc/             # Administrative utilities, mount daemons, and YP tools (yp/)
├── games/           # BSD games suite
├── hosts/           # Network hosts table generator (MAKEHOSTS)
├── include/         # System header files including NFS and RPC headers
├── lib/             # C library, troff macros, learn routines
├── man/             # Section 1 through 8 manual pages
├── spool/           # Mail and printer spool directories
├── ucb/             # Berkeley user utilities
└── src/             # Complete Wisconsin 4.3BSD source tree
    ├── sys/         # 4.3BSD kernel with Sun NFS & RPC integration
    │   ├── nfs/        # Sun Microsystems NFS 2.0 kernel implementation
    │   ├── rpc/        # Kernel-mode Sun Remote Procedure Call (RPC) layer
    │   ├── sys/        # Machine-independent core routines, sockets, FFS
    │   ├── vax/        # Machine-dependent DEC VAX assembly and traps
    │   ├── vaxuba/     # UNIBUS device drivers
    │   ├── vaxmba/     # MASSBUS device drivers
    │   ├── netinet/    # TCP/IP protocol suite
    │   ├── net/        # Core network routing and interfaces
    │   └── conf/       # Kernel configuration rules
    ├── ucb/         # Userland Berkeley utilities source
    ├── bin/         # Standard system commands source
    ├── etc/         # Network daemons, NFS mountd, and portmap source
    ├── usr.bin/     # Standard userland utilities source
    ├── usr.etc/     # Wisconsin administrative utilities source
    └── lib/         # C runtime library source
```

## Key Source Code Files
| File Path | Description & Architectural Significance |
| :--- | :--- |
| `src/sys/nfs/nfs_vfsops.c` | **First BSD NFS integration:** VFS filesystem operations for mounting and unmounting Sun NFS on 4.3BSD. |
| `src/sys/nfs/nfs_vnodeops.c` | Vnode operations mapping standard file read/write/lookup calls into NFS remote RPC calls. |
| `src/sys/nfs/nfs_server.c` | Kernel-mode NFS server handling incoming client requests on the VAX. |
| `src/sys/rpc/clnt_kudp.c` | Kernel-level UDP client for executing Sun RPC remote procedure calls. |
| `src/sys/rpc/svc_kudp.c` | Kernel-level UDP server dispatching incoming Sun RPC procedure calls. |
| `src/sys/rpc/xdr.c` | eXternal Data Representation (XDR) serialization and deserialization routines. |
| `src/etc/portmap.c` | Sun RPC portmapper daemon source code. |
| `src/etc/rpc.mountd.c` | NFS mount daemon handling client mount requests and `/etc/exports` permissions. |

## Recommended Exploration Path
1. **Study the Earliest BSD NFS Integration (`src/sys/nfs/`):**
   - Read `src/sys/nfs/nfs_vfsops.c` and `nfs_vnodeops.c` to see how the Wisconsin team grafted Sun's early NFS code onto the 4.3BSD kernel.
2. **Examine Kernel-Level RPC (`src/sys/rpc/`):**
   - Read `src/sys/rpc/clnt_kudp.c` and `svc_kudp.c` to see how remote procedure calls were executed directly inside the kernel over UDP sockets.
3. **Inspect Yellow Pages / NIS Authentication (`etc/yp/`):**
   - Trace how centralized network host and password maps were distributed across systems.
4. **Review Userland Daemons (`src/etc/`):**
   - Trace how `portmap` and `rpc.mountd` coordinated with the kernel to negotiate remote filesystem exports.
