# V8 Source Code Archive

## Historical Overview
- **Release / Snapshot Date:** February 1985
- **Authors & Key Contributors:** Dennis Ritchie, Ken Thompson, Doug McIlroy, Brian Kernighan, Rob Pike, Peter J. Weinberger, Tom J. Killian, Dave Presotto, Norman Wilson, and Bell Telephone Laboratories researchers (Computing Science Research Center, Department 1127).
- **Target Machine Architecture:** DEC VAX-11/750 and VAX-11/780 (32-bit virtual memory architecture with hardware page tables, demand paging, and UNIBUS/MASSBUS peripherals).
- **Historical Milestones:**
  - **The Shift to 32-Bit VAX & Virtual Memory:** After Seventh Edition, Research Unix moved from the 16-bit PDP-11 to DEC's 32-bit VAX architecture. Starting from 32V and incorporating virtual memory paging concepts from UC Berkeley's 4.1BSD, the Bell Labs team rebuilt the operating system with true 32-bit flat address spaces.
  - **The Invention of Streams I/O:** Dennis Ritchie published and integrated **Streams** (*A Stream Input-Output System*, AT&T Bell Laboratories Technical Journal, 1984). Streams replaced the inflexible, monolithic Unix TTY driver with modular, bidirectional pipelines of message-passing processing blocks (`struct queue`). Modules could be dynamically pushed onto or popped off device stream heads using `ioctl(fd, I_PUSH, ...)`.
  - **The Birth of the `/proc` Filesystem:** Tom Killian invented **`/proc`** (*Processes as Files*, USENIX Summer 1984, implemented in `usr/sys/sys/proca.c`). By exposing running processes as file paths (`/proc/01234`), debuggers could examine and control processes using standard `open()`, `read()`, `write()`, and `lseek()` calls, completely eliminating the notoriously fragile and machine-dependent `ptrace()` system call.
  - **Bitmapped Graphics & Blit Terminal:** Rob Pike and Bart Locanthi designed the Blit (Teletype DMD 5620 / Jerq) programmable graphics terminal, integrating mouse-driven windowing and asynchronous terminal multiplexing directly into the research Unix environment.
  - **Source Provenance:** Preserved from Bell Laboratories research backup distributions and donated by Bell Labs researchers to the Unix Heritage Society (TUHS).

## Key Source Code Files

| Component / Subsystem | File Link | Description |
| :--- | :--- | :--- |
| **Dennis Ritchie's Streams Subsystem** | `usr/sys/dev/stream.c`, `usr/sys/h/stream.h` | The original Streams character I/O implementation: defines `struct queue`, `struct qinit`, message queues, `putq()`, `getq()`, queue scheduling, and `qopen()`/`qclose()`. |
| **The Historic `/proc` Filesystem** | `usr/sys/sys/proca.c` | Tom Killian's original `/proc` implementation: maps process memory segments (text, data, stack, user area) into filesystem byte offsets, handling process control `ioctl` operations and process memory reads/writes. |
| **Kernel Entry & Paging Bootstrap** | `usr/sys/sys/main.c` | 32-bit VAX bootstrap: initializes virtual page tables, mounts root filesystem, configures swap maps, and initializes process 0. |
| **Virtual Memory Pager** | `usr/sys/sys/vmproc.c`, `usr/sys/sys/vmswap.c` | Demand paging, page table management, core allocation, and page fault resolution on VAX hardware. |
| **Process Scheduler & Dispatcher** | `usr/sys/sys/slp.c` | VAX 32-bit scheduler: `sleep()`, `wakeup()`, run queue manipulation, and priority re-evaluation. |
| **Path Traversal & Inode Cache** | `usr/sys/sys/nami.c`, `usr/sys/sys/iget.c` | Hierarchical directory parsing and memory inode table caching. |
| **Block Buffer Cache** | `usr/sys/dev/bio.c` | Block caching subsystem managing I/O queues and device buffer headers. |
| **Datakit Network Subsystem** | `usr/src/dk/`, `usr/sys/dev/dk.c` | A. G. Fraser's Datakit network interface drivers and userland routing daemons. |
| **The Rob Pike Sam Editor** | `usr/src/cmd/sam/` | Early source of Rob Pike’s structural regular expression text editor `sam`, designed for bitmapped terminals. |
| **Kernel Internal Headers** | `usr/sys/h/param.h`, `usr/sys/h/proc.h`, `usr/sys/h/user.h` | 32-bit kernel definitions for process descriptors, signal handlers, and execution context. |

## Recommended Exploration Path

To understand the 32-bit architectural revolution introduced in Eighth Edition:

1. **Study Dennis Ritchie's Streams Subsystem:**
   Begin by reading `usr/sys/h/stream.h`, followed by `usr/sys/dev/stream.c`. Notice how modular queues (`struct queue`) allowed character processing modules to be dynamically composed.
2. **Explore the Invention of `/proc`:**
   Read Tom Killian's `usr/sys/sys/proca.c`. Trace how file offsets in `/proc/<pid>` are mapped to VAX page tables (text, data, stack, and `u.` area), allowing standard file I/O to inspect and modify live processes.
3. **Trace VAX Demand Paging:**
   Read `usr/sys/sys/vmproc.c` and `usr/sys/sys/vmswap.c` to see how Research Unix implemented virtual memory on the VAX hardware.
4. **Inspect Early Network and GUI Software:**
   Look at `usr/src/dk/` for Datakit networking, and explore `usr/src/cmd/sam/` to see Rob Pike's windowed editor.
